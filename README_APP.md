# hreborn - 美食地图应用

## 应用简介

**hreborn** 是一个基于地图的美食搜索和路线规划应用，帮助用户快速找到附近的美食，查看外卖信息，并规划最佳路线。

## 核心功能

### 1. **实时地图定位**
- 应用启动时自动获取用户的当前位置
- 在地图上显示用户位置（蓝色标记）
- 支持手动刷新位置

### 2. **美食搜索**
- 在搜索栏输入想要的美食名称（如"火锅"、"寿司"等）
- 系统自动搜索用户位置附近的相关美食店铺
- 搜索结果显示距离、地址和外卖信息

### 3. **外卖信息查询**
- 每个搜索结果都显示该餐厅是否支持外卖
- 支持外卖的餐厅标记为绿色"支持外卖"
- 不支持外卖的餐厅标记为灰色"仅到店"

### 4. **路线规划**
- 点击任意搜索结果可选择该餐厅
- 点击"开始导航"按钮打开 Google Maps 进行导航
- 显示餐厅详细信息和距离

### 5. **底部导航**
- **地图**：主要功能页面，实时地图和美食搜索
- **数据**：显示健康数据统计和分析
- **我的**：用户个人资料管理
- **关于**：应用介绍和功能说明

## 技术栈

- **前端框架**：React 18 + TypeScript
- **UI 组件库**：shadcn/ui
- **地图服务**：OpenStreetMap + Nominatim
- **动画库**：Framer Motion
- **样式**：Tailwind CSS
- **路由**：React Router v6
- **构建工具**：Vite

## 使用指南

### 第一次使用
1. 打开应用，允许浏览器访问您的位置
2. 地图会自动显示您的当前位置
3. 在搜索栏输入想要的美食名称

### 搜索美食
1. 在搜索栏输入美食名称（如"麻辣烫"、"烤肉"等）
2. 点击搜索按钮或按 Enter
3. 系统会在下方显示找到的美食店铺列表

### 查看详情和导航
1. 点击任意美食卡片
2. 查看餐厅详细信息、距离和外卖支持情况
3. 点击"开始导航"按钮使用 Google Maps 导航

### 重新定位
- 点击右下角的蓝色位置按钮可重新获取您的当前位置

## 页面说明

### 地图页面（首页）
- 搜索栏：输入美食名称进行搜索
- 地图区域：显示您的位置和搜索结果
- 美食卡片：展示搜索结果，支持横向滑动

### 我的页面
- 个人资料管理
- 身高、体重、健康目标设置
- 账户设置和退出登录

## 常见问题

### Q: 无法获取位置怎么办？
A: 请检查浏览器是否允许访问位置权限。如果被拒绝，应用会默认使用上海作为位置。

### Q: 搜索不到结果怎么办？
A: 
- 确保输入的美食名称正确
- 尝试使用更通用的名称（如"餐厅"、"饭店"）
- 检查网络连接

### Q: 外卖信息准确吗？
A: 外卖信息目前是随机生成的演示数据。在生产环境中，可以集成真实的美食配送平台 API（如美团、饿了么等）。

## 开发者指南

### 项目结构
```
src/
├── pages/           # 页面组件
│   ├── MapPage.tsx      # 地图和美食搜索页面
│   ├── DashboardPage.tsx # 数据统计页面
│   ├── ProfilePage.tsx   # 用户资料页面
│   └── ...
├── components/      # 可复用组件
│   ├── layout/          # 布局组件
│   └── ui/              # UI 组件库
├── hooks/          # 自定义 Hooks
├── lib/            # 工具函数
└── App.tsx         # 主应用组件
```

### 添加新功能

1. **添加新页面**：在 `src/pages/` 创建新文件，然后在 `App.tsx` 中添加路由

2. **使用 UI 组件**：从 `@/components/ui/` 导入所需组件

3. **调用外部 API**：在 `src/hooks/` 创建自定义 Hook 处理数据
